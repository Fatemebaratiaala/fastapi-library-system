# fastapi-library-system

یک API ساده برای مدیریت کتابخانه که با FastAPI 
توی نسخه قبلی اطلاعات کتاب‌ها توی یک دیکشنری پایتون نگهداری می‌شد که با هر بار ری‌استارت شدن سرور از بین می‌رفت.
توی این نسخه دیتاها به PostgreSQL منتقل شدن و از SQLAlchemy برای ارتباط با دیتابیس استفاده کردم

اول پکیجو نصب کنید:
```bash
pip install -r requirements.txt
